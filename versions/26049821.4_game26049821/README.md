- 读回不一致不再直接判失败：`memory_scan.write_verified` 会重新写入并重读，最多 3 次；并区分“游戏把数值改回去了”和“这次读回失败（0 字节）”。

- 战士快速移动的“移动回合”写入同样改为重试 + 瞬时错误，不再因一次抢占中止整个锁定周期。
- 新增 `write_conflict` 事件：记录地址、写入前字节、期望字节、实际读回字节和重试次数，便于事后定性。
